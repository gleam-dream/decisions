# Decisions design coverage

- The design captures three contexts, record, storage and runtime, and records designed-but-unbuilt capabilities and open owner decisions in each context's pending ledger.
- Contexts follow vocabulary, not packages: the core package holds the record context and the storage port, its memory adapter and conformance suite; each integration package holds part of storage and part of runtime.
